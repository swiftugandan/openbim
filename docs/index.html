Outside judges

Nothing counts as done until someone else's tool agrees.

Every task is checked by a judge written before the code. Where an independent open-source tool exists, the judge asks it: the same IFC file through ifcopenshell, the same frame through PyNite, the same pipe network through EPANET.

How it is built

One task at a time, in the open.

An autonomous loop works through the plan. Each task gets a fresh Claude Code session that runs these stages, then a gate that trusts none of it.

01

Scout

Maps what already exists and what the task touches.

02

Plan

Lays out modules, algorithms and edge cases before code.

03

Build

Implements against the frozen contract.

04

Check

Runs the task's judge, exactly once.

05

Audit

A fresh reviewer writes its own probes to break the claims.

06

Commit

The gate reruns this judge and every earlier one, then commits.

A failed task gets one fix round and one retry on a stronger model. A task that still fails is marked blocked, with its reason, and so is everything that depends on it.

Command line

Everything the app can do, a script can do.

The CLI contract is frozen in spec/cli.md, so the commands below are what each task must deliver.

$ bim init tower
$ bim apply tower walls.json
$ bim solve tower --trade struct --json
$ bim validate tower --standard eurocode --json
$ bim clash tower --clearance 0.05 --json
$ bim export tower --format ifc --out tower.ifc
$ bim export tower --format pdf --view plan:L1@1.2 --out l1.pdf
$ bim diff tower 3f9c0a1e8d2b4c77 a01be6d94f3c2e58 --json
# exit 0 ok · 1 found a problem · 2 invalid input · 3 internal error
