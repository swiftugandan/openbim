openbim

Free, open-source software for designing and checking buildings.

openbim keeps a building as one model. From that model it works out room areas, structural forces and pipe pressures, checks the design against building rules and produces drawings.

It is written in the Rust programming language. It will run on your computer and in a web browser.

What openbim will do

openbim is split into 10 parts. Each part is built and checked as a set of numbered tasks.

Store and share models

Keeps a full history of every change. Several people can edit the same model at once without losing work. When 2 changes conflict, the conflict is recorded in the model so someone can resolve it.

Tasks T1.1 to T1.7 and T3.1 to T3.3

Work out shapes

Calculates the exact shape of walls, floors and openings, including where elements join or cut through each other. Keeps the sizes and alignments you set as rules.

Tasks T2.1 to T2.6

Model directly in 3D

Draw lines, rectangles, circles and arcs, then push or pull faces into solids, in the same way as SketchUp. The cursor snaps to corners, edges, faces and the red, green and blue axes, and you can type exact sizes.

Tasks T2.10 to T2.12, T8.6 and T8.7

Produce drawings

Draws plans, sections and elevations with standard line weights, hatching and dimensions. Saves them as SVG, PDF and DXF files.

Tasks T2.7 to T2.9 and T7.4

Run engineering checks

Calculates room areas and volumes, forces and deflections in beams and columns, and pressures and flows in pipe networks. Finds elements that clash.

Tasks T4.1 to T4.7

Add other trades

Other trades, such as fire protection, can be added later as plugins without changing openbim. A plugin can add its own types of element, calculations and checks. It runs in a sandbox, so it cannot read your files or use the network.

Tasks T1.8 and T4.8

Use manufacturers’ products

Import a manufacturer’s catalogue of doors, windows, furniture, paints, floor finishes and roof coverings. Place its products in the model, and get door, window and finish schedules from it.

Tasks T4.9, T5.8 and T8.5

Follow industry standards

Reads and writes IFC, the open file format for building models. Tracks design issues in BCF format. Checks designs against building rules, such as the International Building Code and Eurocodes.

Tasks T5.1 to T5.9

Work the way you do

You can use openbim from the command line, in a web app, or through an AI assistant. AI assistants connect using the Model Context Protocol, and every change they suggest is checked before it is saved.

Tasks T6.1 to T6.3, T8.3 and T8.4

Show the model in 3D

Displays the model in a web browser. You can select elements and cut the model open with a section box. Drawing sheets stay sharp on high-resolution screens.

Tasks T7.1 to T7.3, T8.1 and T8.2

How the work is checked

Each task has a test that was written before any code. A task is only marked as done when its test passes.

Where possible, the test compares openbim’s answer with an established open-source tool. For example:

  • IFC files are checked with IfcOpenShell
  • structural results are checked with PyNite
  • pipe networks are checked with EPANET, through WNTR
  • 3D shapes are checked with Manifold and trimesh
  • the web app is checked for accessibility with axe-core

Some tests also set a pass mark. For example:

  • merging changes must give the same model in 10,000 random cases
  • engineering results must be within 0.1% of the textbook answer
  • the 3D view must draw at 60 frames per second with 100,000 elements

How openbim is being built

An automated process builds openbim one task at a time, using Claude Code. For each task it:

  1. looks at the code that already exists
  2. writes a plan, for the simpler tasks
  3. writes the code
  4. runs the task’s test
  5. asks a separate reviewer to look for problems
  6. runs this test and every earlier test again, then saves the work

If a task fails twice, it is marked as blocked and the reason is recorded. Tasks that depend on it are also blocked.

You can see the progress of every task in the build plan.

Using the command line

Every feature will be available from the command line, so you can use openbim in scripts. These are some of the planned commands:

$ bim init tower
$ bim apply tower walls.json
$ bim solve tower --trade struct --json
$ bim validate tower --standard eurocode
$ bim export tower --format ifc --out tower.ifc

The full list is in the command-line specification.
